# bachelor-project-Feldman-VSS
This is the source code of my implementation and analysis of the Feldman's VSS under dishonest majority assumption. The implementation built on the protocols described in the paper "Feldman's VSS under dishonest majority" by Chen and Lindell. 

The second file, FROST DKG, is the implemented distibuted key generation protocol described in the paper "FROST: Flexible Round-Optimized Schnorr Threshold Signatures" by Chelsea Komlo and Ian Goldberg. The DKG relies on the Feldman VSS with dishonest majority assumptions.
